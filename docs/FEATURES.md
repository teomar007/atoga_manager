# الميزات — Features
> عربي / English — صفحة يدوية تُحدَّث عند إضافة ميزة. Hand-maintained.

## الدخول والصلاحيات — Login & Roles
- دخول باليوزر نيم، طلب وصول/انتظار/رفض، حجب أدوار التوصيل — username login + access flow + role gating.
- تبويبات حسب الدور (super_admin/manager/marketer) — role-based tabs.

## لوحة المعلومات — Dashboard
- KPIs اليوم (مبيعات/تسليم/قيد الانتظار/متوسط) — daily KPIs.
- سلسلة مبيعات (يوم/أسبوع/شهر/سنة) + الأعلى/الأقل مبيعاً — sales series + top/least products.

## الكتالوج — Catalog
- منتجات: إضافة/تعديل/حذف/إخفاء + صورة ImageKit + سعر عرض — products CRUD + ImageKit images.
- تصنيفات: CRUD + حذف آمن + 90 أيقونة وبحث عربي/فرنسي/إنجليزي — categories CRUD + 90-icon picker (AR/FR/EN search).
- ترجمة تلقائية عربي→فرنسي — auto AR→FR translation.

## التسويق — Marketing
- بنرات (صورة/لون، محاذاة/تكبير، ترتيب، تصنيف) — banners.
- كوبونات (أنواع/حدود/ترحيبي/تواريخ) — coupons.
- إشعارات فورية/مجدولة (duration حدد) + سجل — instant & scheduled pushes + log.

## المحفظة — Wallet
- بحث زبون، شحن/خصم RPC، سجل حركات — customer search, credit/debit, history.

## الزبائن وأوقات العمل والموظفون
- زبائن: بحث/إحصاءات/تجميد بسبب (ينعكس فوراً على الزبون) — customers: freeze with reason.
- أوقات العمل والورديات — store hours & shifts.
- موظفون: إنشاء/تعديل/كلمة مرور/تجميد/حذف/إحصاءات — employees full lifecycle + stats.

## الإعدادات — Settings
- اللغة، روابط الدعم (هاتف/واتساب/سوشيال)، مناطق التوصيل — language, support links, delivery zones.
